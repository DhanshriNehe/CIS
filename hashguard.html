About Project

Cryptography & Information Security (CIS) — College Project

Abstract

MD5 and SHA-1 are cryptographically broken for collision resistance, yet remain embedded in legacy code and configuration. HashGuard is a lightweight static analyser that locates such usage with regular-expression rules and presents the results with evidence and remediation advice.

Problem statement

Deployed software artifacts often still call weak hash APIs for integrity checks, signatures or password storage. Manual review is slow and error-prone, so a quick automated detector is needed.

Objectives

  • Detect MD5 and SHA-1 API calls and algorithm strings
  • Classify findings by severity
  • Show code evidence with file and line
  • Recommend safer alternatives
  • Export HTML, CSV and JSON reports

Rules

  • WH001 MD5 API usage — High
  • WH002 SHA-1 API usage — High
  • WH003 Legacy hash algorithm string in config — Medium

Limitations & future work

  • Regex matching can yield false positives/negatives
  • No data-flow analysis of how the hash is used
  • Compiled binaries are not inspected
  • Future: AST analysis, CI integration, SARIF output, more algorithms (e.g. DES, RC4)
